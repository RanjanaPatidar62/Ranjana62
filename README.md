# Machine Learning Projects Collection 🚀

This repository contains various Machine Learning projects ranging from classification to regression tasks. Each project includes a dedicated Jupyter Notebook and the necessary dataset.

## 📁 Projects Overview

1. Customer Churn Prediction 📉
 Goal: Predict whether a customer will leave a service (churn) based on their usage patterns and demographics.
 Tech Stack: Python, Pandas, Scikit-learn, Matplotlib.
 File: Customer churn prediction.ipynb

2. Early Disease Detection 🏥
 Goal: Use medical data to identify potential health risks at an early stage for better treatment outcomes.
 Tech Stack: Python, Scikit-learn, Numpy.
 File: Early disease detection.ipynb

3. Property Price Prediction 🏠
 Goal: Estimate the market value of real estate properties based on features like area, location, and amenities.
 Tech Stack: Regression Models, Seaborn, Pandas.
 File: Property price prediction.ipynb
